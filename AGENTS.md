# Dental Care project notes

- This checkout is the Dental Care app; use the `dental-care` origin.
- The WMS-Toho GitHub repository is a read-only source template and must not be pushed to or modified remotely.
- Local database bootstrap is `database/dental_care.sql`; do not use the template's WMS bootstrap for this app.
- Keep browser API calls same-origin under `/api`; local Next.js forwarding uses `API_PROXY_TARGET`.
- Do not reuse or print database credentials from the source template.
